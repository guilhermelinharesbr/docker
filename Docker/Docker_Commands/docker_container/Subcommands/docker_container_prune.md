### Descrição

O **docker container prune** remove todos os containers parados.

---

### Sintaxe

docker **container prune** [OPTIONS]

---

### Opções

As opções podem ser vistas por meio do comando `docker container prune --help` sendo elas:

- **-f**,**--force** -> Não pede confirmação via prompt.

---

### Exemplos

Ex:
```bash
docker container prune
```
