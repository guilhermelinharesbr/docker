#### Exercício

![Criando_primeiro_Dockerfile.png](/images/Dockerfile/Criando_primeiro_Dockerfile.png)

[Link do repositório do exercício](https://github.com/techeducabr/curso-docker-essencial-card-business)

Rodar os seguinte comandos:
```bash
cd ~
mkdir projeto
cd projeto
git clone https://github.com/techeducabr/curso-docker-essencial-card-business.git
cd curso-docker-essencial-card-business/card-business
tree
apt install python3.12-venv
python3 -m venv venv
ls venv
# Ativando o ambiente virtual:
source venv/bin/activate
# Instalando depedências:
pip install --no-cache-dir -r requirements.txt
pip install "werkzeug<3.0.0"
python app.py
```

Agora pode acessar no navegador:
http://192.168.0.200:8080/

Será visto algo como:
![tela_da_aplicacao_em_python_1.png](/images/Dockerfile/tela_da_aplicacao_em_python_1.png)

Continuando nos comandos:
```bash
# Parando a aplicação:
Ctrl +C
export IDADE=20
python app.py
```

Será visto algo como:
![tela_da_aplicacao_em_python_2.png](/images/Dockerfile/tela_da_aplicacao_em_python_2.png)

Continuando nos comandos:
```bash
# Parando a aplicação:
Ctrl +C
# Desativando o ambiente virtual do Python
deactivate
# Para tornar uma imagem da aplicação é preciso criar um Dockerfile na raiz do projeto 
vim Dockerfile
```

Conteúdo do Dockerfile:
```txt
# cat Dockerfile

FROM ubuntu:22.04
RUN apt update && \
    apt install python3.11 python3.11-dev python3-pip -y 
WORKDIR /app
COPY . .
RUN pip3 install --no-cache-dir -r requirements.txt
EXPOSE 8080 
ENV LOGOMARCA="https://cdn.discorapp.com/attachments/10744800287853858995/1110782090032709643/logomarca-azul-1000x235.png"
ENV FOTO="https://cdn.discorapp.com/attachments/1074800287853858997/1113253295033696337/image.png"
ENV NOME="Guilherme"
ENV IDADE="20"
ENV EMAIL="teste@dominio.com.br"
ENV PROFISSAO="Analista de TI"
ENV SITE="www.teste.com.br"
CMD [ "python3", "app.py" ]
```

Continuando nos comandos:
```bash
# Fazendo o build, esse processo demora alguns minutos:
docker build -t meu-app-python:v1 .
# Listando a imagem criada:
docker image ls -a
# Obs: O nome dela ficou meu-app-python:v1.
docker run -dit --name container-meu-app -p 8080:8080 meu-app-python:v1
docker container ls -a
```

Acessando via navegador:
http://192.168.0.200:8080/
