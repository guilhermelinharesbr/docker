### Descrição

O **docker volume ls** lista os volumes.

---

### Sintaxe

docker **volume ls**

---

### Opções

As opções podem ser vistas por meio do comando `docker volume ls --help` sendo elas:

- **-q**, **--quiet** -> Mostra apenas os nomes dos volumes.

---

### Exemplos

Ex. lista os volumes:
```bash
docker volume ls
```
