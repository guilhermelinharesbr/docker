### Descrição

O **docker volume** é o comando usado para gerenciar os volumes do Docker.

O diretório padrão dos volumes docker é **/var/lib/docker/volumes/**.

---

### Subcomandos

O comando docker system possui diversos subcomandos, que podem ser vistos na subpasta [docker_volume](Subcommands/) deste repositório.
