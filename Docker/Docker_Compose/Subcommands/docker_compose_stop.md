### Descrição

O **docker compose stop** interrompe a execução de containeres sem removê-los. Eles podem ser iniciados novamente com o comando [docker compose start](docker_compose_start.md).

Para os containers que façam parte de um mesmo compose file.

---

### Sintaxe

docker **compose stop** [OPTIONS] [SERVICE...]
