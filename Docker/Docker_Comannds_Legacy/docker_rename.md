### Descrição

O **docker container rename** renomeia containers.  
O container não precisa estar parado para ser renomeado.

---

### Sintaxe

docker **container rename** CONTAINER NEW_NAME

---

### Apelido

docker **rename** 

---

### Exemplos

Ex:
```bash
docker rename nome_atual_container novo_nome_container
```
