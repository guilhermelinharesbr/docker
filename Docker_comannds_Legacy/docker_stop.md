### Descrição

O **docker stop** 


---

### Sintaxe

docker **container stop** [OPTIONS] CONTAINER [CONTAINER...]

---

### Apelido

docker **stop** 

---

### Opções

As opções podem ser vistas por meio do comando `docker stop --help` sendo elas:

- **-t**,**--timeout** int -> Para que aguardar tantos segundo antes de parar o container.


---

### Exemplos

Ex. :
```bash
docker stop meu-ubuntu
ou
docker stop 87hk #87hk é o começo do ID do container
```
