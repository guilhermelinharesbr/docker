### Descrição

O **docker** é o comando base para gerenciar containers, imagens, volume, redes, etc.

---

### Sintaxe

**docker** [OPTIONS]

---

### Opções

As opções podem ser vistas por meio do comando `docker --help`, `dcoker help`, `docker -h` ou apenas `docker` sendo elas:

- **-v**, **--version** -> mostra a versão docker de maneira bem resumida, litando-se a apenas uma linha. A maneira de ver as informações mais completas da versão do docker é o [docker version](docker_version.md).

---

### Exemplos

Ex:
```bash
docker help
ou
docker -h
ou
docker --help
ou
docker
```

Ex2:
```bash
docker -v
```
