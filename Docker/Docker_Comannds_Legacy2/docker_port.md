### Descrição

O **docker port** Lista os mapeamentos de portas ou um mapeamento específico para o container.

---

### Sintaxe

docker **container port** CONTAINER [PRIVATE_PORT[/PROTO]]

---

### Apelido

docker **port** 

---

### Exemplos

Ex:
```bash
docker port nome_container
ou 
docker port id_container
```
