### Descrição

Este artigo mostrará como manipular volumes no docker.

---

### Prática

Será mostrado como criar, lista, excluir um volume do docker.

```bash
# Criando um volume chamado vol-ubuntu:
docker volume create vol-ubuntu


# Listando os volumes:
docker volume ls
```
