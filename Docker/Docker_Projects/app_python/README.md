# Docker Projetc: Aplicação Python básica com FastAPI rodando em containers

---


```bash
docker build -t minha-api-python:1.0.0 .
docker compose up -d
docker image ls
docker compose ls
docker container ls -a
```

ou

```bash
docker compose up -d
docker image ls
docker compose ls

```
